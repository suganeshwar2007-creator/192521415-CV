
# Experiment 31 - Image Segmentation Using OpenCV

## Aim
To segment an input image based on given threshold values using OpenCV.

## Software Requirements
- Python
- OpenCV
- Matplotlib
- Google Colab

## Algorithm
Thresholding Segmentation

## Procedure
1. Upload the input image.
2. Read the image using OpenCV.
3. Convert the image into grayscale.
4. Define the lower and upper threshold values.
5. Apply binary thresholding.
6. Apply inverse thresholding.
7. Apply range-based segmentation using cv2.inRange().
8. Display and save the segmented images.

## Result
Image segmentation was successfully performed using OpenCV based on the specified threshold values.
