
# Experiment 35 - Add Text on Image Using OpenCV

## Aim
To display a user-entered text string on an image using OpenCV.

## Software Requirements
- Python
- OpenCV
- Matplotlib
- Google Colab

## Procedure
1. Upload an input image.
2. Read the image using OpenCV.
3. Get a text string from the user.
4. Create a copy of the original image.
5. Add text using cv2.putText().
6. Display and save the output image.

## Result
User-entered text was successfully displayed on the input image using OpenCV.
