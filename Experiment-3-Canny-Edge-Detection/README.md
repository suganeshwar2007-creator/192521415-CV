
# Experiment 3: Canny Edge Detection

## Aim
To read an image in Python and detect its outline
using the Canny edge detection function in OpenCV.

## Libraries Used
- Python
- OpenCV
- Matplotlib

## Method
1. Read the input image.
2. Convert the image to grayscale.
3. Apply cv2.Canny() with thresholds 100 and 200.
4. Display and save the edge-detected image.

## Result
The outline of the input image was detected using
