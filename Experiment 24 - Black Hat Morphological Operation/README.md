
# Experiment 24 - Black-Hat Morphological Operation Using OpenCV

## Aim
To implement the Black-Hat morphological operation using Python and OpenCV.

## Libraries Used
- Python
- OpenCV
- Matplotlib

## Procedure
1. Read the input image.
2. Convert the image to grayscale.
3. Create a structuring element.
4. Apply the Black-Hat operation using cv2.morphologyEx().
5. Display and save the output images.

## Output
The original, grayscale, and Black-Hat images are displayed.

## Result
The Black-Hat morphological operation was successfully implemented using Python and OpenCV.
