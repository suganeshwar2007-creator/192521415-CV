
# Experiment 28 - Vehicle Detection Using OpenCV

## Aim
To detect and locate vehicles in each frame of a video using OpenCV.

## Software Requirements
- Python
- OpenCV
- Ultralytics YOLOv8
- Google Colab

## Algorithm
YOLOv8 Object Detection

## Procedure
1. Upload the input video.
2. Load the pretrained YOLOv8 model.
3. Read the video frame by frame using OpenCV.
4. Detect cars, motorcycles, buses, and trucks.
5. Draw bounding boxes around detected vehicles.
6. Save all processed frames into an output video.

## Result
Vehicles were successfully detected and located in each video frame using OpenCV and YOLOv8.
