# Experiment 9 - Image Scaling Using OpenCV

## Aim
To implement image scaling techniques to resize an image to bigger and smaller sizes using OpenCV.

## Libraries Used
- Python
- OpenCV
- Matplotlib

## Method
1. Read the input image using OpenCV.
2. Obtain the original image dimensions.
3. Enlarge the image using `cv2.resize()` with a scale factor of 2.
4. Reduce the image using `cv2.resize()` with a scale factor of 0.5.
5. Display the original, enlarged, and reduced images.
6. Save the output images.
