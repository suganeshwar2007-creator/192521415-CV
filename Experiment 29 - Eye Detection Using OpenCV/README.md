
# Experiment 29 - Eye Detection Using OpenCV

## Aim
To detect and locate human eyes in an image using OpenCV.

## Software Requirements
- Python
- OpenCV
- Matplotlib
- Google Colab

## Algorithm
Haar Cascade Classifier

## Procedure
1. Upload an image containing a human face.
2. Read the image using OpenCV.
3. Convert the image into grayscale.
4. Load the Haar Cascade eye detection classifier.
5. Detect eyes using detectMultiScale().
6. Draw rectangular bounding boxes around detected eyes.
7. Display and save the output image.

## Result
Human eyes were successfully detected and located using OpenCV.
