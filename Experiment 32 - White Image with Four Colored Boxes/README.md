
# Experiment 32 - White Image with Four Colored Boxes Using OpenCV

## Aim
To create a white image of user-defined size and draw four colored boxes at its corners.

## Software Requirements
- Python
- OpenCV
- NumPy
- Matplotlib
- Google Colab

## Procedure
1. Get image width and height from the user.
2. Create a white image using NumPy.
3. Calculate box dimensions as 1/10th of the image size.
4. Draw black, blue, green and red boxes at the four corners.
5. Display and save the image.

## Result
A white image with four colored boxes at its corners was successfully created using OpenCV and NumPy.
