# Experiment 7 - Video Processing Using OpenCV

## Aim
To read a captured video in Python and display it in slow motion and fast motion.

## Libraries Used
- Python
- OpenCV
- Google Colab

## Method
1. Read the captured video using OpenCV.
2. Extract the video frame rate and resolution.
3. Create a slow-motion video by reducing the playback frame rate.
4. Create a fast-motion video by processing every alternate frame.
5. Display and save both processed videos.

## Output
- [Slow Motion Video](slow_motion.mp4)
- [Fast Motion Video](fast_motion.mp4)

## Result
The captured video was successfully read and processed to produce slow-motion and fast-motion videos using Python and OpenCV.
