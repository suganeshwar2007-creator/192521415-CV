# Experiment 13 - Affine Transformation Using OpenCV

## Aim
To perform affine transformation on an input image using Python and OpenCV.

## Libraries Used
- Python
- OpenCV
- NumPy
- Matplotlib

## Method
1. Read the input image using OpenCV.
2. Define three source points and three destination points.
3. Calculate the affine transformation matrix using `cv2.getAffineTransform()`.
4. Apply the transformation using `cv2.warpAffine()`.
5. Display the original and transformed images.
6. Save the output images.
