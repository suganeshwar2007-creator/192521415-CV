
# Experiment 20 - Image Dilation Using OpenCV

## Aim
To implement morphological dilation to expand foreground regions using Python and OpenCV.

## Libraries Used
- Python
- OpenCV
- Matplotlib

## Procedure
1. Read the input image.
2. Convert the image to grayscale.
3. Apply binary thresholding.
4. Create a structuring element.
5. Apply dilation using cv2.dilate().
6. Display and save the processed images.

## Output
The original, binary, and dilated images are displayed.

## Result
The morphological dilation operation was successfully implemented using Python and OpenCV.
