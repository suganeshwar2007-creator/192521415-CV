# Experiment 10 - Image Rotation Using OpenCV

## Aim
To perform a 90-degree clockwise rotation on an input image using OpenCV.

## Libraries Used
- Python
- OpenCV
- Matplotlib

## Method
1. Read the input image using OpenCV.
2. Convert the image from BGR to RGB for display.
3. Rotate the image by 90 degrees clockwise using `cv2.rotate()`.
4. Display the original and rotated images.
5. Save the output images.
