
# Experiment 21 - Morphological Opening Using OpenCV

## Aim
To implement the morphological opening operation using Python and OpenCV.

## Libraries Used
- Python
- OpenCV
- Matplotlib

## Procedure
1. Read the input image.
2. Convert the image to grayscale.
3. Apply binary thresholding.
4. Create a structuring element.
5. Apply opening using cv2.morphologyEx().
6. Display and save the output images.

## Output
The original, binary, and opening images are displayed.

## Result
The morphological opening operation was successfully implemented using Python and OpenCV.
