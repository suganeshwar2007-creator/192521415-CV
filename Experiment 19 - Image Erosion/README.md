
# Experiment 19 - Image Erosion Using OpenCV

## Aim
To implement the morphological erosion operation using Python and OpenCV.

## Libraries Used
- Python
- OpenCV
- Matplotlib

## Procedure
1. Read the input image.
2. Convert the image to grayscale.
3. Apply binary thresholding.
4. Create a structuring element.
5. Apply erosion using cv2.erode().
6. Display and save the processed images.

## Output
The original, binary, and eroded images are displayed.

## Result
The morphological erosion operation was successfully implemented using Python and OpenCV.
