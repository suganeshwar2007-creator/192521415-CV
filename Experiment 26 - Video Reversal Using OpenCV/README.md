
# Experiment 26 - Video Reversal Using OpenCV

## Aim
To reverse the frames of a video and create a video in reverse mode using OpenCV.

## Software Requirements
- Python
- OpenCV
- Google Colab

## Procedure
1. Upload the input video.
2. Read the video using cv2.VideoCapture().
3. Store all frames in a list.
4. Reverse the order of the frames.
5. Write the reversed frames using cv2.VideoWriter().
6. Save and display the reversed video.

## Result
The input video was successfully converted into reverse mode using OpenCV.
