
# Experiment 27 - Face Detection Using OpenCV

## Aim
To detect and locate human faces in an image using OpenCV.

## Software Requirements
- Python
- OpenCV
- Matplotlib
- Google Colab

## Algorithm
Haar Cascade Classifier

## Procedure
1. Upload an image.
2. Read the image using OpenCV.
3. Convert the image into grayscale.
4. Load the Haar Cascade face detection classifier.
5. Detect faces using detectMultiScale().
6. Draw rectangular bounding boxes around detected faces.
7. Display and save the output image.

## Result
Human faces were successfully detected and located using OpenCV.
