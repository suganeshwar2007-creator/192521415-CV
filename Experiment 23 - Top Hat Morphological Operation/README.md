
# Experiment 23 - Top-Hat Morphological Operation Using OpenCV

## Aim
To implement the Top-Hat morphological operation using Python and OpenCV.

## Libraries Used
- Python
- OpenCV
- Matplotlib

## Procedure
1. Read the input image.
2. Convert the image to grayscale.
3. Create a structuring element.
4. Apply the Top-Hat operation using cv2.morphologyEx().
5. Display and save the output images.

## Output
The original, grayscale, and Top-Hat images are displayed.

## Result
The Top-Hat morphological operation was successfully implemented using Python and OpenCV.
