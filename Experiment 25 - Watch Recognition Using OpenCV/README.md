
# Experiment 25 - Watch Recognition Using OpenCV

## Aim
To recognize a watch in an image using general object recognition techniques with OpenCV.

## Software Requirements
- Python
- OpenCV
- PyTorch
- Transformers
- Matplotlib
- Google Colab

## Procedure
1. Upload an image containing a watch.
2. Read the image using OpenCV.
3. Load a pre-trained OWL-ViT object detection model.
4. Detect the watch and obtain its bounding box.
5. Draw a bounding box and confidence score.
6. Display and save the output image.

## Result
Watch recognition was performed using a pre-trained object detection model and OpenCV.
