
# Experiment 18 - Image Cropping, Copying and Pasting ROI Using OpenCV

## Aim
To implement image cropping, copying, and pasting to select a Region of Interest (ROI) from the source image using OpenCV.

## Libraries Used
- Python
- OpenCV
- Matplotlib

## Procedure
1. Read the input image using OpenCV.
2. Select a rectangular Region of Interest (ROI).
3. Crop the selected region.
4. Copy the ROI using the copy() function.
5. Paste the copied ROI into another location in the image.
6. Display and save the output images.

## Output
The original image, cropped ROI, and copied-and-pasted image are displayed.

## Result
Image cropping, copying, and pasting of the selected Region of Interest were successfully implemented using Python and OpenCV.
