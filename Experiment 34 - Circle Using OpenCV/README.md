
# Experiment 34 - Circle Using OpenCV

## Aim
To create a white image of user-defined size and draw a circle using OpenCV.

## Software Requirements
- Python
- OpenCV
- NumPy
- Matplotlib
- Google Colab

## Procedure
1. Get image width and height from the user.
2. Create a white image using NumPy.
3. Calculate the center and radius of the circle.
4. Draw a red circle using cv2.circle().
5. Display and save the output image.

## Result
A circle was successfully created on a white image using OpenCV.
