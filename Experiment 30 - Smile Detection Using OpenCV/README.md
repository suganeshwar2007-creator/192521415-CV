
# Experiment 30 - Smile Detection Using OpenCV

## Aim
To detect and locate human smiles in an image using OpenCV.

## Software Requirements
- Python
- OpenCV
- Matplotlib
- Google Colab

## Algorithm
Haar Cascade Classifier

## Procedure
1. Upload an image containing a human face.
2. Read the image using OpenCV.
3. Convert the image into grayscale.
4. Load the Haar Cascade face and smile classifiers.
5. Detect faces in the image.
6. Detect smiles in the lower part of each face.
7. Draw rectangular bounding boxes around detected smiles.
8. Display and save the output image.

## Result
Human smiles were successfully detected and located using OpenCV.
