
# Experiment 4: Histogram Equalization Using OpenCV

## Aim
To implement histogram equalization on an image and
compare the result with the original image using OpenCV.

## Libraries Used
- Python
- OpenCV
- Matplotlib

## Method
1. Read the input image.
2. Convert it to grayscale.
3. Apply cv2.equalizeHist() to improve contrast.
4. Display the original and equalized images.
5. Compare their intensity histograms.
